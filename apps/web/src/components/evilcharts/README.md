# Evil Charts

Source: [Evil Charts composed chart](https://evilcharts.com/docs/recharts/composed-chart/static)

Fetched through the official `@evilcharts` shadcn registry on 2026-10-04.
The upstream components retain their compound API and MIT license.

Local adaptations: project import paths, custom tooltip content for exact decimal
money, signed bar geometry, and chart container accessibility/flex sizing.
Dashboard usage disables chart and tooltip animations.
